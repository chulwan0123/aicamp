# 구현 현황과 보완 과제

## 제품 목표

주택 자산 비중이 높고 현금흐름이 부족한 시니어와 부모님의 노후를 준비하는 자녀가 주소 입력을 시작점으로 세금과 자산 유동화 대안을 비교하도록 돕습니다.

## 현재 화면 계약

- 최초 진입: 본 화면 번호와 분리된 `#start` 스플래시
- 본 화면: plushome 계약의 0~18번, 총 19개
- 입력: 1/8 연령, 2/8 주택 수·명의, 3/8 주소, 4/8 실거래가, 5/8 취득·거주, 6/8 희망 지역, 7/8 성향·소득, 8/8 최종 확인
- 분석: 최소 5초 동안 분석 영상을 표시한 뒤 결과로 이동
- 결과: 요약, 세금, 현금흐름, 다운사이징, 종합 추천, 주택연금, 상속·증여
- 기타: 홈, 마이, 세제개편안, 본 화면 번호와 분리된 AI 상담 오버레이

화면 번호와 해시의 정확한 매핑은 `디자인_보호_가이드.md`를 기준으로 합니다.

## 구현된 엔진과 API

### 데이터 수집

- 입력 화면의 기존 `radio`·`select`·주소 필드를 그대로 원본 상태로 사용합니다.
- 주소 검색은 `hyeji0503/hanwhaAiCamp`의 구현을 기준으로 다음 주소검색을 사용합니다. 도로명주소 입력은 검색 선택으로만 변경되며, 검색 결과의 법정동코드·산 여부·지번으로 19자리 PNU를 생성합니다.
- 공시가격은 PNU를 `/api/price`로 보내 국토교통부 NSDI 공동주택가격 API에서 서버 조회합니다. 새 주소를 선택하면 이전 조회값을 지우고 주택별 로딩·성공·실패·재시도 상태를 관리합니다. API 키는 `PUBLIC_DATA_API_KEY` 환경변수에만 둡니다.
- 실거래가·면적 등 계산용 주택 정보는 `data/properties.json`에서 조회하며, 미등록 주소를 반포자이 등 다른 주택으로 임의 대체하지 않습니다.
- 반포자이 기본 데이터는 120동 1002호, 전용 84.94㎡, 32평형, 최근 실거래가 47억원, 취득가 10억 8,247만원입니다.

### 계산·추천

- `api/_lib/**`의 plushome 규칙 엔진이 재산세, 종합부동산세, 양도소득세, 주택연금, 부분 임대, 다운사이징, 매도·금융운용, 증여 검토를 계산합니다.
- 종합부동산세에는 재산세 중복분 차감을 반영합니다.
- 2027년 고령 1주택 양도세 특례는 연령, 1주택, 현재 수도권, 희망 비수도권의 네 조건을 모두 확인합니다.
- OpenAI는 계산된 숫자를 새로 만들지 않고 성향 기반 설명과 추천을 작성합니다. 검증 실패, 키 미설정, 호출 실패 시에는 현재 계산값으로 규칙 기반 추천을 생성합니다.
- API 요청은 입력 검증, 본문 크기 제한, 간단한 요청 빈도 제한을 적용합니다.

### 결과 화면에 노출하는 ZIP 전체 계약

- 성향 점수 3개와 판단 메모, 연간 보유세·연간 부족액
- 4개 유동화 선택지의 적격 여부, 월 세후액, 대안·제외 사유와 남는 자산
- 추천 총유입·차감·순액·충족률, 감수할 점, 주의사항, 가족 전달문
- 정확도 지표, 추가 확인 9항목, 반영 조건과 계산 가정
- 현금흐름·보유세·양도세·특례·추천·주택연금·증여의 전체 산식과 근거
- 세금, 매도·임차, 다운사이징, 종합 추천, 주택연금, 증여 상세의 전체 자금 내역

### 저장·공유

- 계산 결과는 브라우저에 저장해 홈 요약과 상세 화면에 다시 반영합니다.
- 공유 링크는 AES-256-GCM 인증 암호화 토큰을 사용하며 7일 후 만료됩니다.
- API 키와 공유 비밀키는 서버 환경변수에서만 읽고 클라이언트나 저장소에 넣지 않습니다.

## 배포 구조

- 정적 화면: `index.html`, `assets/**`, `js/**`, `data/**`
- 서버리스 API: `/api/advise`, `/api/share`, `/api/price`, `/api/health`
- 운영 환경: Vercel
- 로컬 실행: `npm run dev`
- 검증: `npm run check`
- 주 저장소: `https://github.com/chulwan0123/aicamp`
- 공동 작업 저장소: `https://github.com/hyeji0503/hanwhaAiCamp`

두 저장소의 배포 대상 트리는 같은 SILVER 통합 결과로 유지합니다. 주소 검색·PNU·공시가격 API의 출처는 `hyeji0503/hanwhaAiCamp`, 화면·디자인 계약과 통합 계산 엔진의 기준은 `chulwan0123/aicamp`입니다.

## 아직 부족한 기능

### 외부 데이터·인증

- 카카오 OAuth 로그인, 실제 가족 관계와 권한 관리
- 입력·결과의 서버 데이터베이스 저장과 기기 간 동기화
- 국토교통부 실거래가 API의 실시간 연결과 공시가격 조회 실패 시 수동 입력 흐름
- 부모님 초대, 전문가 상담 예약, 공지·콘텐츠 상세의 실제 백엔드

### 계산 정확도·운영

- 확정 시행 법령과 과세연도별 규칙 버전 관리
- 전년도 고지세액을 사용하는 법정 세부담 상한의 정밀 계산
- 다주택·지분별 취득가·채무·필요경비를 각각 입력하는 구조
- 주택연금 공식 보증기관 조회와 상품별 지급 방식
- 물가, 수익률, 의료·돌봄비를 포함한 확률 시뮬레이션
- 세무 전문가 기준 사례와 실제 고지·신고 결과를 이용한 오차 검증

### 개인정보·보안

- 개인정보 동의, 보유기간, 삭제 요청 처리
- 서버 저장 도입 시 주소·자산 정보의 저장 암호화와 접근 기록
- 분산형 요청 제한과 악용 탐지
- 공유 링크 철회와 접근 감사
