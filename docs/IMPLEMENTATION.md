# 구현 현황과 보완 과제

> 운영 기준일: 2026-08-21. 운영 URL은 `https://aicamp-sigma.vercel.app`이다.

## 제품 목표

주택 자산 비중이 높고 현금흐름이 부족한 시니어와 부모님의 노후를 준비하는 자녀가 주소 입력을 시작점으로 세금과 자산 유동화 대안을 비교하도록 돕습니다.

## 현재 화면 계약

- 취득가·공시가격·예상 매매가격을 입력하거나 자동으로 불러오면 입력칸 아래에 `15억 원`, `5천만 원`처럼 읽기 쉬운 한글 금액을 바로 표시합니다.
- 입력 화면의 문서·화면 가로 넘침을 차단해 필드 입력 중 좌우 흔들림을 막고, 가격 확인 필드는 카드 없이 다른 입력 페이지와 같은 42px 간격으로 배치합니다.
- 최초 진입: 본 화면 번호와 분리된 `#start` 스플래시
- 본 화면: plushome 계약의 0~18번, 총 19개
- 입력: 1/8 부모님 연령대, 2/8 주택 수·주택별 공동명의, 3/8 서울·경기 아파트·동호수, 4/8 공시가격·전용면적·현재 예상 매매가격 확인, 5/8 주택별 취득연도·취득가·거주기간 구간, 6/8 서울·경기 희망 지역, 7/8 성향·월소득 구간, 8/8 최종 확인
- 분석: 최소 5초 동안 분석 영상을 표시한 뒤 결과로 이동
- 결과: 요약, 세금, 현금흐름, 다운사이징, 종합 추천, 주택연금, 상속·증여
- 기타: 홈, 마이, 세제개편안, 본 화면 번호와 분리된 AI 상담 오버레이

화면 번호와 해시의 정확한 매핑은 `디자인_보호_가이드.md`를 기준으로 합니다.

## 구현된 엔진과 API

### 데이터 수집

- 나이와 거주기간, 월소득은 외부 기준 데모와 같은 구간 선택으로 간소화했습니다. 계산에는 연령대와 거주기간 구간의 보수적인 하한값, 월소득 구간 대표값, 서울 부부 적정 노후생활비 329만 6천원을 사용합니다. 예를 들어 `2년 이상 5년 미만`은 2년, `5년 이상 10년 미만`은 5년으로 계산합니다.
- 과거 실제 거주기간과 현재 거주 여부는 다른 정보로 취급합니다. 간소화 화면은 현재 거주 주택을 별도로 묻지 않으므로 첫 번째 주택을 현재 거주지로 자동 판정하지 않고, 현재 거주가 필요한 보유세 공제는 보수적으로 제외합니다.
- 새 집 가격·공시가격, 임차보증금, 의료·간병 예비자금, 부분임대 수입, 목표생활비는 입력받지 않습니다. 임차 비교에는 규칙셋의 서울 전용 84㎡ 전세 보증금 가정치 15억원, 의료 예비자금에는 0원을 사용하며 다운사이징은 새 집 가격을 받지 않으므로 금액 비교에서 제외합니다. 이 기준값과 월소득 구간 계산값은 결과의 `현재 계산에 사용한 가정`에 표시합니다.
- 취득가는 양도소득세를 다른 주택의 고정값이나 임의 비율로 계산하지 않기 위해 주택별 필수 입력으로 유지합니다. 공동명의는 별도 지분율을 묻지 않고 50:50으로 계산합니다.
- 운영 배포는 다음 주소검색 결과의 법정동코드·산 여부·지번으로 19자리 PNU를 생성합니다.
- 공시가격은 국토교통부 2025년 주택 공시가격 파일에서 서울 2,755,045세대·경기 4,383,843세대, 합계 7,138,888세대를 PNU 앞 7자리별 압축 조각으로 생성해 `/api/price`에서 조회합니다. PNU·동·호·전용면적이 일치하지 않으면 다른 세대 가격으로 대체하지 않으며 공시가격 조회에는 API 키가 필요 없습니다.
- `/api/market`은 `DATA_GO_KR_API_KEY`로 국토교통부 아파트 매매·전월세 실거래 상세 자료를 조회합니다. PNU의 시군구·지번, 단지명, 전용면적이 모두 같은 거래만 사용하고 취소 매매를 제외합니다. 매매 중앙값은 수정 가능한 현재 예상 매매가격으로 제시하고 전세·월세 통계는 참고 근거로만 표시합니다.
- 실거래 원본은 시군구·월별로 6시간 서버 캐시하고, 조회 결과는 Vercel CDN에서 재검증 가능하게 캐시합니다. 공공데이터 키는 클라이언트에 전달하지 않습니다.
- `data/properties.json`은 정확한 주소·동·호가 모두 일치할 때 단지명과 면적을 보조하는 검증 발췌본입니다. 다른 동·호의 면적·가격·취득가를 가져오지 않습니다.
- 정상 입력 화면에는 반포자이·판교·마포 주소, 공시가격, 시세, 취득연도, 취득가 기본값이 없습니다.
- 단지와 전용면적을 선택하면 해당 면적의 2025년 공시가격 최소·최대 범위 중간값을 `동일 면적 유사값`으로 먼저 입력합니다. 전용면적에 실제로 등록된 동·호수는 목록 모달로 선택할 수 있고, 선택하면 해당 세대의 정확한 공시가격으로 교체합니다. 유사값과 정확한 조회값은 모두 다음 화면에서 사용자가 확인·수정할 수 있습니다.
- 단지 선택 시 도로명주소를 자동으로 채웁니다. 사용자는 같은 입력 화면의 `주소 검색` 버튼으로 주소를 직접 다시 찾을 수 있고, 검색된 PNU와 일치하는 등록 단지를 자동으로 연결한 뒤 전용면적 선택으로 이어집니다.
- 정확한 세대 조회가 실패해도 이미 선택한 단지·전용면적의 유사값을 유지합니다. 단지·면적 범위조차 없을 때만 사용자가 공시가격과 전용면적을 직접 입력하며, 수정값은 `사용자 입력` 출처로 보존합니다.

### 계산·추천

- `api/_lib/**`의 plushome 규칙 엔진이 재산세, 종합부동산세, 양도소득세, 주택연금, 부분 임대, 다운사이징, 매도·금융운용, 증여 검토를 계산합니다.
- 종합부동산세에는 재산세 중복분 차감을 반영합니다. 2027·2028년 기본공제, 공정시장가액비율, 세율표, 거주 중심 세액공제와 금액 한도는 2026년 세제개편안 원문을 별도 규칙으로 적용합니다.
- 2·3주택은 첫 주택만 계산하지 않고 주택별 재산세와 합산 공시가격 기준 종합부동산세를 계산합니다.
- 2027년 고령 1주택 양도세 특례는 발표된 개편안의 what-if로만 분리합니다. 법률 확정 전에는 추천 금액과 현재 세후 수령액에 적용하지 않습니다.
- 매도·임차와 다운사이징의 금융자산 인출액은 전체 필요 생활비가 아니라 `필요 생활비 - 기존 소득 + 정기비용`으로 계산해 소득을 중복 합산하지 않습니다.
- 다운사이징은 새 집 가격을 임의로 추정하지 않습니다. 간소화된 입력 흐름에서는 새 집 매매가격·공시가격을 받지 않으므로 정확한 가격이 필요한 다운사이징 금액 비교를 제외합니다.
- OpenAI는 계산된 숫자를 새로 만들지 않고 성향 기반 설명과 추천을 작성합니다. `/api/chat`도 현재 저장된 분석 결과와 세제개편안 검증 메모를 바탕으로 실제 답변하며, 키 미설정 시에는 같은 계산값을 사용하는 규칙 기반 답변으로 전환합니다.
- API 요청은 입력 검증, 본문 크기 제한, 간단한 요청 빈도 제한을 적용합니다.

### 결과 화면에 노출하는 ZIP 전체 계약

- 성향 점수 3개와 판단 메모, 연간 보유세·연간 부족액
- 4개 유동화 선택지의 적격 여부, 월 세후액, 대안·제외 사유와 남는 자산
- 추천 총유입·차감·순액·충족률, 감수할 점, 주의사항, 가족 전달문
- 외부 데모와 같은 순서의 추천 상세 6개 구역: `왜 이 방법일까요?`, `대신 이런 점은 감수하셔야 해요`, `이건 꼭 확인해 주세요`, `매달 이렇게 들어와요`, `다른 방법은 어떨까요?`, `이 순서로 준비하시면 돼요`
- 정확도 지표, 추가 확인 9항목, 반영 조건과 계산 가정
- 현금흐름·보유세·양도세·특례·추천·주택연금·증여의 전체 산식과 근거
- 세금, 매도·임차, 다운사이징, 종합 추천, 주택연금, 증여 상세의 전체 자금 내역

### 저장·공유

- 계산 결과는 브라우저에 저장해 홈 요약과 상세 화면에 다시 반영합니다.
- 공유 링크는 AES-256-GCM 인증 암호화 토큰을 사용하며 7일 후 만료됩니다.
- 결과 공유와 부모님 초대는 카카오 JavaScript SDK의 `Kakao.Share.sendDefault()`를 우선 호출하고, 미설정·미지원 환경에서는 기기 공유 또는 클립보드 복사로 대체합니다.
- 부모님 초대는 같은 암호화 결과 링크를 사용하고, 전문가 상담은 연락처·희망 시간·동의를 검증한 뒤 결과 토큰만 상담 웹훅으로 전달합니다.
- 알림 설정은 브라우저 알림 권한을 확인하고 허용된 경우 실제 확인 알림을 표시합니다.
- 뉴스·콘텐츠·공지·고객센터와 마이 분류 메뉴는 기존 바텀시트·상세 화면 패턴으로 연결합니다.
- API 비밀키와 공유 비밀키는 서버 환경변수에서만 읽고 저장소에 넣지 않습니다. 카카오 JavaScript 키는 `/api/client-config`로 필요한 값만 전달하고 등록 도메인으로 사용 범위를 제한합니다.

### 서울·경기 단지 검색

- 운영에는 `시/도 → 시/군/구 → 단지명 → 전용면적 → 동·호` 순서의 검색 UI와 `GET /api/complexes`가 배포돼 있습니다.
- 2025년 서울·경기 69개 시군구 gzip 조각과 192,195개 단지 색인을 사용합니다.
- 이 작업은 반포자이 고정값이나 다른 단지 폴백을 사용하지 않습니다.
- `index.html`의 3단계 문구·DOM·레이아웃을 변경했으며 시각 QA 증거는 `design-qa.md`에 기록돼 있습니다.
- 모바일 편집 필드는 iOS 포커스 확대를 막도록 최소 16px를 사용합니다.
- 선택한 도로명주소는 PNU와 함께 별도 상태에 보존하며 입력칸 값이 유실돼도 다음 단계에서 복원합니다.
- 현재 `npm run check`는 84개 테스트가 통과합니다.

## 확인된 출시 차단 계산 결함

- `capitalGainsTax()`의 12억원 초과분 과세비율이 `houseCount`와 무관하게 적용돼 다주택에도 1주택 산식이 들어갑니다.
- `saleForYear()`가 각 주택의 `isAdjustedArea`를 양도세 함수에 전달하지 않아 조정대상지역 다주택 중과가 빠질 수 있습니다.

이는 다주택 보유세 합산 경로와 별개의 양도세 문제입니다. 수정·테스트·세무 검증 전에는 다주택 양도세를 출시 완료로 판정하지 않습니다.
