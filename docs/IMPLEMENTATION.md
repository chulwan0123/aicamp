# 구현 현황과 보완 과제

## 제품 목표

주택 자산 비중이 높고 현금흐름이 부족한 시니어와 부모님의 노후를 준비하는 자녀가 주소 입력을 시작점으로 세금과 네 가지 유동화 대안을 비교하도록 돕습니다.

## 구현된 사용자 흐름

1. 시작 화면에서 서비스 로고와 소개 영상을 확인하고 시작합니다.
2. 홈에서 서비스 소개, 예상 결과 미리보기와 자산관리 콘텐츠를 확인합니다.
3. 부모님 연령대를 입력합니다.
4. 보유 주택 수와 주택별 공동명의 여부를 선택합니다.
5. 도로명주소와 상세주소를 입력합니다.
6. 최근 실거래가 조회 결과를 확인합니다.
7. 취득연도와 거주기간을 입력합니다.
8. 은퇴 후 희망 지역을 선택하고 입력값을 확인합니다.
9. 분석 화면을 거쳐 결과 요약으로 이동합니다.
10. 세금, 주택연금, 임차·금융운용, 다운사이징, 상속·증여 상세 결과를 확인합니다.
11. AI 노후 컨설팅 대화, 부모님 공유 또는 상담 행동으로 이어집니다.

## 화면 구성

- 시작: SILVER 로고, 캐치프레이즈, 자동 재생 배경 영상, 시작하기 CTA
- 홈: 로띠 인사 비주얼, 영상 시작 카드, 예상 결과 그래프, 재방문 사용자 부모님·주택 요약, 가로 뉴스 배너, 세로 콘텐츠 목록
- 입력: 공통 고정 헤더와 분리된 7단계 진행 막대, 하단 고정 다음 버튼, 심플 체크를 사용하는 선택용 하단 시트
- 결과: 현금흐름 부족액, AI 추천, 시나리오별 요약, FAQ, 상세 페이지 연결
- AI 상담: 결과 기반 추천 질문과 사용자 메시지에 응답하는 대화형 UI
- 마이: 내 결과·부모님 초대·세제 안내·공지사항·고객센터 바로가기, 추천 카드, 서비스 분류와 로그아웃
- 세제개편안: 종부세 기본공제, 공정시장가액비율, 거주공제, 양도소득세 관련 안내

## 화면 상태와 라우팅

- 각 화면은 `#start`, `#home`, `#parents-age`, `#result`, `#my`, `#ai-consulting` 등의 해시 주소로 구분합니다.
- 새로고침하거나 브라우저 뒤로가기를 사용해도 현재 해시 화면을 복원합니다.
- 주소에 유효한 해시가 없으면 시작 화면으로 이동합니다.
- 로그아웃은 사용자 상태를 초기화하지 않고 시작 화면으로 이동하는 프로토타입 동작입니다.

## 디자인과 미디어

- LIFEPLUS Bold를 주요 타이틀에 적용합니다.
- PLUS 오렌지 60(600, `#F37521`)을 핵심 버튼, 진행 상태, 선택 상태와 그래프 강조색으로 사용합니다.
- 홈 카드와 시작 화면의 MP4는 무음 자동 재생·반복·인라인 재생으로 동작합니다.
- 홈 상단 장식은 로컬 Lottie 런타임과 번들된 애니메이션 데이터로 실행합니다.

## 모바일 대응

- `viewport-fit=cover`와 iOS 안전영역 반영
- 320px 이상 작은 화면에서 주소 검색·세금 그리드·홈 CTA 재배치
- 모바일에서는 흰색 전체 화면, 데스크톱에서는 회색 배경 위 최대 500px 콘텐츠 영역
- 하단 탭·CTA·하단 시트에 안전영역 여백 적용
- 터치 목표와 가로 스크롤 배너 최적화

## 아직 부족한 기능

### 데이터와 인증

- 카카오 OAuth 로그인 및 사용자 계정
- 부모님 초대 링크, 가족 관계 연결, 권한 관리
- 입력값·분석 결과의 서버 저장과 기기 간 동기화
- 주소 검색, 공동주택 공시가격, 국토교통부 실거래가 API

### 계산 정확도

- 재산세·종합부동산세·양도소득세 규칙 엔진
- 공동명의, 다주택, 조정대상지역, 취득가액, 필요경비, 보유·거주기간별 계산
- 법령 시행일과 과세연도별 버전 관리
- 주택연금 공식 가입 조건과 월 지급금 조회
- 임차료, 금융수익률, 물가, 의료·돌봄비를 포함한 확률 시뮬레이션

### 사용자 경험

- 입력값 유효성 검사와 오류·빈 상태
- 주소 및 주택이 여러 채일 때의 편집·삭제 흐름
- 카카오톡 리포트 공유와 PDF 리포트
- 전문가 상담 예약, 공지사항, 콘텐츠 상세
- 웹 접근성 자동 검사와 실기기 회귀 테스트

### 운영과 보안

- 개인정보 동의, 보유기간, 삭제 요청 처리
- 주소·자산 등 민감정보 암호화와 접근 기록
- 세금 계산 근거·기준일·출처 노출
- 분석 오차율, 가족 연결률, 실행 전환율 측정
