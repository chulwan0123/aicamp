```text
당신은 SILVER 프로젝트의 “로직 연결 전담 에이전트”다. 현재 구현된 디자인을 수정하거나 다시 설계하는 역할이 아니다.

1. 저장소 루트의 AGENTS.md를 처음부터 끝까지 읽어라.
```

## 두 에이전트에게 일을 나누는 권장 방식

시각 파일 충돌을 막기 위해 화면별로 나누기보다 책임 레이어로 나누는 편이 안전하다.

### 에이전트 A: 도메인·계산 로직

- 입력 데이터 모델
- 세금, 주택연금, 현금흐름 계산
- 포맷터와 유효성 검사
- 순수 함수 테스트
- DOM과 CSS를 직접 수정하지 않음

### 에이전트 B: 연동·상태 로직

- API 어댑터
- 저장과 복원
- 로그인, 공유, 상담 연결
- 기존 DOM에 이벤트와 결과값 연결
- 화면 수정은 `data-*` 추가와 값 주입 수준으로 제한

두 에이전트가 동시에 `index.html`을 수정하지 않는다. DOM 연결이 필요한 변경은 한 명만 담당하고, 다른 한 명은 별도 로직 파일과 테스트만 작성한다.

## 조정자가 먼저 해야 할 일

1. 현재 디자인 변경을 한 커밋으로 확정한다.
2. 두 에이전트에게 같은 커밋 해시를 전달한다.
3. 각자의 파일 소유 범위를 명시한다.
4. `index.html` 수정 권한은 한 에이전트에게만 준다.
5. 병합 전 디자인 QA 담당자가 화면을 비교한다.

이 순서를 지키면 기능 개발 속도를 유지하면서 디자인 기준선이 다른 PC에서 갈라지는 문제를 크게 줄일 수 있다.
