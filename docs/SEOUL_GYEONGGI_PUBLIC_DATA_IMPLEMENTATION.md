# 서울·경기 부동산 공공데이터 3종 출시 구현 보고서

## 결론

반포자이 고정값이나 다른 단지 폴백 없이 아래 3종을 실제 출시 경로에 연결했다.

1. 서울·경기 아파트 매매 실거래
2. 서울·경기 아파트 전월세 실거래
3. 서울·경기 아파트 동·호수별 공동주택 공시가격

대출액과 부모님 소득액은 이 세 데이터의 조회·필터·시세 제안에 사용하지 않는다. 서비스 지역은 서울특별시와 경기도로 제한한다.

## 공시가격

- 원본: 국토교통부 `주택 공시가격 정보_20250626`, 공공데이터포털 데이터 3073746
- 기준연도: 2025년
- 반영 건수: 서울 2,755,045세대 + 경기 4,383,843세대 = 7,138,888세대
- 저장: `data/public-price/2025/` 아래 PNU 앞 7자리 기준 257개 gzip 조각, 총 약 66MB
- 조회 키: PNU + 동 + 호 + 전용면적
- API: `GET /api/price`
- 실패 원칙: 동·호가 맞지 않으면 같은 PNU의 다른 세대 가격도 반환하지 않는다.
- 표시 원칙: 2025년 공시가격이며 2026년 확정 공시가격으로 표현하지 않는다.

폐기된 `ApartHousingPriceService` 실시간 API와 반포자이 한 건짜리 시드 폴백은 출시 조회 경로에서 제거했다. 새 원본 생성은 아래 명령으로 재현한다.

```bash
node scripts/build-public-price-shards.js "/path/to/국토교통부_주택 공시가격 정보_20250626.zip"
```

## 매매·전월세 실거래

- 매매 원본: 국토교통부 아파트매매 실거래 상세 자료
- 임대 원본: 국토교통부 아파트 전월세 자료
- API: `GET /api/market?mode=all`
- 서버 비밀키: `DATA_GO_KR_API_KEY`
- 기본 조회기간: 최근 6개월, 최대 12개월
- 일치 조건: PNU 시군구 + PNU 지번 + 정규화한 단지명 + 전용면적 ±0.3㎡
- 매매: 취소 거래 제외, 건수·중앙값·최저·최고·최근 거래를 반환
- 전월세: 전세와 월세를 분리해 건수와 중앙값을 반환
- 캐시: 시군구·월·자료종류별 6시간 서버 캐시, API 응답 CDN 캐시

매매 중앙값은 화면의 `현재 예상 매매가격` 추천값으로 채우되 사용자가 확인·수정할 수 있다. 전월세는 참고 근거로만 표시하며 부분 임대수입으로 자동 사용하지 않는다. 일치 거래가 없거나 API가 실패하면 다른 단지 가격으로 대체하지 않고 직접 입력을 요구한다.

## 검증 결과

- 공공데이터 3종 출시 기준: 71개 테스트 통과
- 단지 검색, 도로명주소 복원, 모바일 입력 확대 방지와 간소화 계산 회귀 검증 포함 현재 `npm run check`: 84개 테스트 통과
- 공시가격 서울 검증: 반포자이 101동 101호, 전용 84.943㎡, 2025년 2,462,000,000원
- 공시가격 경기 검증: 샛별마을(라이프) 101동 101호, 전용 84.99㎡, 2025년 684,000,000원
- 실제 키 스모크: 반포자이 동일 지번·면적 2026년 1~8월 매매 13건, 중앙값 4,740,000,000원
- 실제 키 스모크: 같은 조건 전월세 104건(전세 48건, 월세 56건)
- 서울·경기 밖 PNU, 잘못된 동·호, 취소 매매, 다른 단지·지번·면적은 제외하는 테스트 포함
- Vercel Production 로컬 빌드 성공: 공시가격 정적 파일 258개(조각 257개 + manifest), `/api/price` 함수 번들 약 16KB로 원본 데이터 중복 포함 제거

## 운영 상태

- Vercel 프로젝트 `aicamp` Production에 `DATA_GO_KR_API_KEY`를 민감 변수로 설정했다.
- 운영 URL: `https://aicamp-sigma.vercel.app`
- 운영 배포에서 `/api/health`, `/api/price`, `/api/market` 실제 조회를 확인했다.
- 현재 불변 배포 URL과 배포 ID는 `vercel inspect`로 확인한다.

## 단지 검색 확장

- `GET /api/complexes`와 `시/도 → 시/군/구 → 단지명 → 전용면적 → 동·호` 선택 흐름이 운영에 배포됐다.
- 2025년 서울·경기 공시가격 원본에서 만든 69개 시군구 gzip 조각과 192,195개 단지 색인을 사용한다.
- 반포자이 또는 다른 단지 고정 폴백은 사용하지 않는다.
- 이 변경은 `index.html`의 3단계 문구·레이아웃을 바꾸며 시각 QA 증거는 `design-qa.md`에 기록돼 있다.
- 모바일 편집 필드는 iOS 자동 확대를 막도록 16px 이상을 사용한다.
- 단지 선택 시 도로명주소를 PNU와 함께 별도 상태에 보존해 입력칸 값이 유실돼도 다음 단계에서 복원한다.
