> 최신 상태(2026-08-21): 운영 배포는 `https://aicamp-sigma.vercel.app`이다. 이 문서의 반포자이 값은 회귀용 샘플이며 운영 기본값이나 폴백이 아니다.

## 문서 목적과 주의사항

현재 서비스에 연결된 plushome 규칙 엔진의 계산 순서와 추천 방식을 기록합니다. 모든 금액은 입력값과 포함된 규칙 버전을 바탕으로 한 예상값입니다. 실제 신고, 과세관청 결정, 금융상품 심사에 그대로 사용할 수 없으며 실행 전 세무·법률·금융 전문가 확인이 필요합니다.

## 출시 전 반드시 수정할 양도세 결함

- 현재 `capitalGainsTax()`는 `houseCount`와 무관하게 12억원 초과분 비율을 계산합니다. 따라서 다주택에도 1세대 1주택용 비과세 구조가 적용될 수 있습니다.
- 현재 `saleForYear()`는 `houseCount`는 전달하지만 주택별 `isAdjustedArea`를 전달하지 않습니다. 조정대상지역 다주택 중과가 누락될 수 있습니다.
- 여러 주택의 보유세 합산 경로와는 별개 문제입니다. “모든 세금이 1주택 기준”이라는 표현도 정확하지 않습니다.

두 결함은 수정·경계값 테스트·세무 검증 전까지 다주택 양도세 출시 차단 항목으로 취급합니다.

## 세금 계산 파이프라인

### 재산세

1. 공시가격에 연도별 공정시장가액비율을 적용합니다.
2. 1세대 1주택 특례 여부에 따라 과세표준 구간별 세율과 누진공제를 적용합니다.
3. 도시지역분과 지방교육세를 계산합니다.
4. 공동명의는 소유 지분을 적용합니다.

### 종합부동산세

1. 명의별 공시가격과 기본공제를 적용합니다.
2. 연도별 공정시장가액비율로 과세표준을 계산합니다.
3. 누진세율과 누진공제로 산출세액을 계산합니다.
4. 종부세 과세분에 대응하는 재산세 중복분을 차감합니다.
5. 적용 가능한 연령·거주 공제를 반영합니다.
6. 농어촌특별세를 합산합니다.

법정 세부담 상한은 전년도 실제 고지세액이 제공될 때 정밀 적용할 수 있습니다. 현재 엔진의 미래연도 값은 포함된 규칙과 입력을 이용한 비교 예상치입니다.

### 양도소득세

```text
양도차익 = 양도가액 - 취득가액 - 필요경비
과세대상 양도차익 = 양도차익 × 고가주택 과세비율
양도소득금액 = 과세대상 양도차익 - 장기보유특별공제
과세표준 = 양도소득금액 - 기본공제
산출세액 = 과세표준별 누진세율 - 누진공제
최종세액 = 산출세액 + 지방소득세
```

2027년 고령 1주택 특례 후보는 다음 네 조건을 모두 충족할 때만 비교합니다.

- 최소 연령 65세 이상
- 1세대 1주택
- 현재 주택이 수도권
- 비수도권으로 이주

개편안과 실제 시행 법령은 다를 수 있으므로 적용 전 법령 시행일과 세부 요건을 다시 확인해야 합니다.

## 유동화 시나리오

1. `PENSION`: 현재 주택 유지 + 주택연금
2. `PARTIAL_RENT`: 거주 유지 + 부분 임대
3. `DOWNSIZE`: 매도 + 더 작은 주택 매수 + 잔여자금 운용
4. `SELL`: 매도 + 임차 + 잔여자금 운용

각 시나리오는 적격 여부, 월 세후 현금흐름, 잔여자산, 비용 내역과 제한 사유를 계산합니다. 증여는 별도 비교 정보로 증여세, 자녀 취득세, 즉시 필요한 현금을 표시합니다.

## 추천 알고리즘

### 성향 점수

- 상속 의향
- 현재 거주 지속 의향
- 생활비 해결 긴급도
- 목돈과 월 현금흐름 선호
- 가족 합의 상태

### 선택 순서

1. 각 시나리오의 법적·상품 적격성을 먼저 확인합니다.
2. 월 부족액 충족 여부와 부모님 성향 적합도를 비교합니다.
3. 세후 월 현금흐름과 잔여자산을 함께 봅니다.
4. 실행 순서와 제외 이유를 생성합니다.
5. LLM을 사용하는 경우에도 엔진 계산 금액을 고정한 뒤 설명만 생성합니다.
6. LLM 결과의 구조와 금액이 검증을 통과하지 못하면 규칙 기반 설명으로 전환합니다.

## 검증 전략

- 단독·공동명의, 1~3주택, 연령·거주기간 경계값 회귀 테스트
- 재산세 중복 차감 전후 비교
- 고령 1주택 특례 네 조건의 개별 실패 테스트
- 미등록 주소의 명시적 오류 테스트
- AI 실패 시 현재 계산값 기반 규칙 추천 테스트
- 공유 토큰 암호화·변조·만료 테스트
- 세무 전문가 대표 사례와 실제 고지·신고 결과 대조
- 과세연도별 규칙 변경 이력과 계산 오차율 관리
