# 세금 기준과 추천 알고리즘

## 문서 목적

현재 화면에 표현된 세금·현금흐름·추천 결과를 실제 서비스로 발전시키기 위한 계산 구조를 정리합니다. 화면의 반포자이 47억원과 세액은 예시값이며 세무 신고나 금융 의사결정에 직접 사용할 수 없습니다.

## 현재 화면의 세금 표현

예시 조건은 반포자이 120동 1002호, 전용 84.94㎡, 32평형, 최근 실거래가 47억원, 1세대 1주택, 2008년 취득, 10년 이상 거주입니다.

| 구분 | 화면 표시값 |
| --- | ---: |
| 2026년 재산세 | 1,520만원 |
| 2026년 종합부동산세 | 1,980만원 |
| 2026년 보유세 합계 | 3,500만원 |
| 2027년 보유세 합계 | 4,410만원 |
| 2028년 보유세 합계 | 4,970만원 |
| 매각 시 양도소득세 | 4억 3,000만원 |
| 지방소득세 포함 매각 세금 | 4억 7,300만원 |

현재 UI는 제공된 2026년 세제개편안 자료의 종부세 기본공제, 공정시장가액비율, 거주공제 전환, 고령 1주택 양도세 특례 방향을 설명합니다. 실제 구현 시에는 개편안과 확정·시행 법령을 구분하고 과세 기준일 기준으로 규칙 버전을 고정해야 합니다.

## 실제 계산에 필요한 입력값

- 소유자별 주택 수와 지분율
- 세대 구성, 1세대 1주택 여부, 공동명의 특례 선택
- 공시가격과 공정시장가액비율
- 취득일, 취득가액, 자본적 지출, 중개수수료 등 필요경비
- 양도 예정일과 예상 양도가액
- 실제 거주기간과 보유기간
- 연령, 장기보유·고령자 공제 요건
- 조정대상지역 및 비수도권 이주 등 지역 조건
- 해당 연도의 세율, 누진공제, 세부담 상한, 지방세율

## 세금 계산 파이프라인

### 재산세

1. 주택별 공시가격을 조회합니다.
2. 과세표준 산정 비율과 세율 구간을 적용합니다.
3. 도시지역분, 지방교육세 등 부가세목을 계산합니다.
4. 세부담 상한과 공동명의 지분을 반영합니다.

### 종합부동산세

1. 납세자별 주택 공시가격을 합산합니다.
2. 해당 연도의 기본공제와 공정시장가액비율을 적용합니다.
3. 세율·누진공제 후 재산세 중복분을 차감합니다.
4. 연령·거주기간·보유기간 공제와 세부담 상한을 반영합니다.
5. 농어촌특별세 등 부가세목을 합산합니다.

### 양도소득세

```text
양도차익 = 양도가액 - 취득가액 - 필요경비
과세대상 양도차익 = 양도차익 × 고가주택 과세비율
양도소득금액 = 과세대상 양도차익 - 장기보유특별공제
과세표준 = 양도소득금액 - 기본공제
산출세액 = 과세표준별 누진세율 - 누진공제
최종세액 = 산출세액 + 지방소득세 + 기타 적용 세액
```

비과세 요건, 고가주택 안분, 장기보유특별공제, 다주택 중과 유예 여부는 양도일의 법령으로 판단해야 합니다.

## 현금흐름 계산

```text
월 부족액 = 목표 월 생활비 - 공적연금 - 개인연금 - 근로·임대·금융소득
세후 매각자금 = 예상 매각가 - 양도 관련 세금 - 거래비용 - 담보대출 상환액
운용 가능 자금 = 세후 매각자금 - 새 거주지 매입가 또는 임차보증금 - 비상자금
월 활용 가능액 = 세후 정기수익 + 계획 인출액
```

물가, 수익률, 주택가격, 의료비는 단일값 대신 보수·기준·낙관 시나리오로 계산하는 것이 적절합니다.

## 추천 알고리즘 제안

### 1. 적격성 필터

- 주택연금 가입 조건 충족 여부
- 1세대 1주택 및 세제 특례 가능 여부
- 거주 지속 의향과 이전 가능성
- 상속 의향과 가족 동의 필요성

### 2. 네 가지 시나리오 생성

1. 현재 주택 유지 + 주택연금
2. 매도 + 다운사이징
3. 매도 + 임차 + 금융운용
4. 거주 유지 + 상속·증여 계획

### 3. 시나리오 점수화

```text
총점 = 현금흐름 충족도 × 0.35
     + 거주 선호 적합도 × 0.20
     + 세후 잔여자산 × 0.20
     + 상속 의향 적합도 × 0.15
     + 위험·변동성 안정성 × 0.10
```

가중치는 사용자 조사와 실행 데이터로 조정하며, 점수와 함께 추천 근거를 노출해야 합니다.

### 4. 5년·10년 계획

- 각 연도의 부모님 연령, 생활비 물가상승, 보유세, 의료·돌봄비를 갱신합니다.
- 현금 고갈 시점과 최소 비상자금 유지 여부를 검사합니다.
- 주택 유지 비용이 감당 범위를 넘거나 건강·이동 조건이 바뀌면 다운사이징 재검토 시점을 제안합니다.
- 상속 예정액과 생전 생활비 사이의 균형을 다시 계산합니다.

### 5. 설명 가능한 추천

결과에는 최소한 다음 근거를 함께 보여줍니다.

- 부모님 연령과 예상 수명 구간
- 현재 집 거주 지속 의향
- 월 필요 생활비와 부족액
- 보유세 증가 전망
- 상속 의향
- 입력 데이터 기준일과 적용 세법 버전

## 검증 전략

- 세무사가 작성한 대표 케이스와 자동 계산 결과 대조
- 1주택·다주택·공동명의·고령자·장기거주 경계값 테스트
- 과세연도별 회귀 테스트와 규칙 변경 이력 관리
- 실제 고지·신고 결과와의 오차율 측정
- 추천 결과가 특정 시나리오를 부당하게 우대하지 않는지 정기 검토
