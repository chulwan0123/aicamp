# 보유세 검증 산식 — 인수인계

> 최신 상태(2026-08-21): 운영 URL은 `https://aicamp-sigma.vercel.app`이다. 서울·경기 2025년 공동주택 공시가격 7,138,888세대가 `/api/price`에 배포됐다. 이 문서의 반포자이 산식은 회귀용이며 운영 폴백이 아니다.

> **통합 주의**: 이 문서의 검증 케이스는 공시가격 34억 9,100만원, 공동명의, 부 70세·모 65세 조건이다. 현재 앱 기본 데이터(공시가격 33억 7,560만원) 및 단독명의 회귀 테스트와 조건이 다르므로 금액을 직접 비교하지 않는다. 현재 코드 회귀값은 `TAX_AND_ALGORITHM.md`와 `tests/engine.test.js`를 기준으로 한다.

법제처 법령 원문(DRF API), 국세청 「2026년 종합부동산세 요약표」, 서울시ETAX 재산세 계산기 실측(9회 호출)으로 3중 검증한 결과다.
반포자이 케이스(공시가 34억 9,100만원 · 부부 공동명의 50:50 · 부 70세 / 모 65세 · 18년 보유·거주 · 1세대1주택)를 원 단위까지 재현한다.

## 0. 먼저 — 조문 번호 정정

재산세 중복분 공제 근거는 **종합부동산세법 시행령 제4조의3**이다. 제4조의2가 아니다.

- 제4조의2 = 1세대 1주택자의 **범위** (일시적 2주택·상속주택·지방저가주택 판정)
- **제4조의3 = 주택분 종합부동산세에서 공제되는 재산세액의 계산** ← 이쪽

화면에 근거 조문을 노출하므로 반드시 맞춰야 한다.

## 1. 재산세

### 1-1. 공정시장가액비율

| 구분 | 공시가격 | 비율 |
|---|---|---|
| 1세대1주택 특례 | 3억원 이하 | 43% |
| | 3억 초과 ~ 6억원 이하 | 44% |
| | **6억원 초과 (9억 초과 포함)** | **45%** |
| 그 외 | — | 60% |

- 근거: 지방세법 시행령 제109조제1항제2호 단서 (대통령령 제36364호, 2026.5.29)
- **"9억원을 초과하는 주택을 포함한다" 괄호는 2022년 최초 도입 때부터 있었다.** 공시가 10억에서 45%가 ETAX 실측으로 확인됐다.

**⚠️ 유효기간이 2026년도분 한정이다.**

| 대통령령 | 공포 | 대상 연도 | 비율 |
|---|---|---|---|
| 제32747호 | 2022.6.30 | 2022 | 일괄 45% |
| 제33609호 | 2023.6.30 | 2023 | 43/44/45% 3구간 신설 |
| 제34528호 | 2024.5.28 | 2024 | 동일 |
| 제35544호 | 2025.5.27 | 2025 | 동일 |
| 제36364호 | 2026.5.29 | **2026** | 동일 |

5년 연속 연장됐지만 매년 5~6월 시행령 개정으로 결정된다. **2027·2028년 전망에 45%를 쓰면 법적 근거가 없다.**

권고 — 전망 연도는 밴드로 표기한다.

> **2027년 이후 전망 (연 962만 ~ 1,240만원)**
> 1세대1주택 재산세 공정시장가액비율 특례(45%)는 2026년분까지만 법에 정해져 있어요.
> · 특례가 연장되면(최근 5년 연속 연장): 약 962만원
> · 특례가 끝나 법정 비율 60%로 돌아가면: 약 1,240만원
> 매년 5~6월에 정해져요.

단일 값이 꼭 필요하면 **60%(법정 본칙)** 를 쓰고 각주를 단다. 과대추정이라 보수적이고 법적으로 방어 가능하다. 45%는 방어 불가.

### 1-2. 과세표준상한

근거: 지방세법 제110조제3항 (신설 2023.3.14, 시행 2024.1.1) / 시행령 제109조의2

```js
// ★ 직전연도 시가표준액에도 "당해연도" 공정시장가액비율을 곱한다 (영 §109의2① 명문)
const capAmount = prevGongsi * currFmvRatio + (currGongsi * currFmvRatio) * 0.05;
const ptBase    = Math.min(currGongsi * currFmvRatio, capAmount);
```

- 과세표준상한율 = **5%** (시행령 제109조의2제2항)
- **발동 임계치**: 공시가격 전년 대비 상승률 > `1/0.95 = 5.26%`. 공정시장가액비율 값과 무관하다.
- **미발동 조건**: 직전연도 시가표준액이 없으면(신축·최초 과세) 시행령이 "해당 연도 시가표준액으로 대체"하도록 해서 `cap = P×r×1.05 > P×r` 이 되어 수학적으로 항상 미발동한다. 별도 예외 조문이 있는 게 아니다.

**직전연도 공시가격을 모를 때는 추정하지 말고 사용자에게 묻는다.**

| 처리 | 총 보유세 | 기준 대비 |
|---|---|---|
| 서초구 평균 +22.07% 추정 | 9,625,781 | — |
| 서울 평균 +18.60% 추정 | 9,859,229 | +2.4% |
| 미상 → 상한 미적용 | 10,899,738 | **+13.2%** |

지역 평균은 단지·동·층·향 편차를 흡수한다. 상승률이 임계치(5.26%) 근처면 상한 발동 여부 자체가 뒤집혀 오차가 비선형으로 증폭된다.

권고 설계:
1. 전년도 공시가격을 **선택 입력**으로 받되 비워둘 수 있게 한다
2. 미입력 시 **상한 미적용**으로 계산하고 "작년 공시가격을 알려주시면 세금이 더 낮아질 수 있어요"라고 안내한다. 과대추정 방향이라 사용자에게 안전하다
3. **추정 공시가격을 확정 금액처럼 산식에 섞지 않는다.** "이렇게 계산했습니다"를 표방하는 앱에서 근거가 무너진다

## 2. 종합부동산세

### 2-1. 파이프라인 (순서가 핵심)

```
① 과세표준  →  ② 산출세액  →  ③ 재산세 중복공제  →  ④ 세액공제(율에 80% 한도)
   →  ⑤ 세부담상한 150%  →  ⑥ 농어촌특별세 20%
```

**③과 ④의 순서를 바꾸면 안 된다.** 종부세법 제9조제6항이 "제1항·제3항 및 제4항에 따라 산출된 세액에 공제율을 곱한다"고 규정한다. 즉 재산세 공제를 먼저 뺀 뒤 공제율을 곱한다. 순서를 바꾸면 이 케이스에서 159만원 → 12만원이 되어 완전히 틀린다.

### 2-2. 과세표준 (법 §8① / 영 §2의4①)

```js
// 방식 B — 공동명의 1주택자 특례 (법 §10의2, 영 §5의2⑥ 지분 합산)
jbBase_B = (3_491_000_000 - 1_200_000_000) * 0.60 = 1_374_600_000

// 방식 A — 지분별 과세 (각자 9억), 1인당 계산 후 ×2
jbBase_A = (3_491_000_000 * 0.5 - 900_000_000) * 0.60 = 507_300_000
```

### 2-3. 산출세액 (법 §9①제1호, 2주택 이하)

```js
gross_B = 9_600_000 + (1_374_600_000 - 1_200_000_000) * 0.013 = 9_826_980
gross_A = 1_500_000 + (  507_300_000 -   300_000_000) * 0.007 = 1_645_110  // 1인당
```

### 2-4. 재산세 중복분 공제 (영 §4의3① — ★제4조의3)

```js
A = 재산세 본세 실제 부과액        // 지방세법 §112①1. 도시지역분·지방교육세 제외
B = reStdRate( jbBase * reFmvRatio )   // 종부세 과표 × 재산세 공정비율 → 재산세 표준세율 적용
C = reStdRate( ptBase )                // 재산세 과세표준 → 재산세 표준세율 적용
공제액 = A * B / C
```

`reStdRate()` = 지방세법 제111조제1항제3호나목 누진표 (3억 초과 시 `570,000 + (x-300,000,000)*0.004`)

**반포자이 계산**

```js
[1] 1_374_600_000 × 0.45 = 618_570_000
[2] B = 570_000 + (618_570_000 - 300_000_000) × 0.004 = 1_844_280
[3] C = 570_000 + (1_570_950_000 - 300_000_000) × 0.004 = 5_653_800
[4] A = 5_653_800
[5] 공제액 = 5_653_800 × 1_844_280 ÷ 5_653_800 = 1_844_280   // A/C = 1 로 약분
```

**약분은 방식 B에서만 성립한다. 방식 A에서는 성립하지 않는다.**

| | A (실제 부과액) | C (재계산 상당액) | A/C |
|---|---|---|---|
| 방식 B | 5,653,800 (주택 전체) | 5,653,800 (주택 전체) | **1.000000** |
| 방식 A | 2,826,900 (전체×50% 안분) | 2,511,900 (지분 과표 누진 재적용) | 1.125403 |

이유: 시행령 제5조의2제7항이 특례 적용 시 "재산세 부과액 및 재산세상당액은 **해당 과세대상 1주택 지분 전체**에 대하여 계산한 금액으로 한다"고 규정해 A와 C가 같은 대상을 가리킨다. 방식 A는 재산세를 물건 전체 과표에 누진 적용 후 지분 안분(지방세법 §113③)하는데, C는 지분 과표에 누진을 **재적용**하므로 어긋난다.

**과표상한이 걸려도 공제액은 변하지 않는다.** A와 C가 같은 값으로 함께 움직여 비율이 항상 1이고, B는 종부세 과세표준에만 의존하는데 과표상한은 지방세법상 재산세 과세표준에만 적용되기 때문이다.

### 2-5. 세액공제 (법 §9⑤~⑨)

```js
const ageRate  = 0.40;   // 만 70세 이상        (§9⑥)  60세 20% / 65세 30% / 70세 40%
const holdRate = 0.50;   // 15년 이상 보유      (§9⑧)  5년 20% / 10년 40% / 15년 50%
const totalRate = Math.min(0.80, ageRate + holdRate);   // ★ 한도는 금액이 아니라 "공제율 합계" (§9⑤ 후단)

afterReCredit = 9_826_980 - 1_844_280 = 7_982_700
netTax        = 7_982_700 * (1 - 0.80) = 1_596_540
```

- 1세대1주택자가 아니면 세액공제는 **0** (영 §2의3①). 방식 A는 세액공제를 받지 못한다
- 보유기간 기산 (영 §4의5): 멸실 후 재건축은 멸실 주택 취득일부터, 배우자 상속은 피상속인 취득일부터
- 공동명의 특례 시 기준자 (영 §5의2⑧): **공동명의 1주택자로 지정된 사람**의 연령·보유기간. 이 케이스는 부(70세) 지정 시 40+50=90%, 모(65세) 지정 시 30+50=80% → 둘 다 한도 80%라 결과 동일

### 2-6. 세부담상한 150% (법 §10 / 영 §5)

적용 지점은 세액공제까지 마친 **결정세액 단계, 농특세 계산 직전**이다.

```js
// 비교 대상은 "재산세 + 종부세" 합계다. 종부세 단독이 아니다
thisYearTotal = ptMain_thisYear + netTax;
finalTax = Math.min(netTax, prevYearTotal * 1.50 - ptMain_thisYear);
```

**전년도 고지서가 필요 없다.** 시행령 제5조제2항이 실제 고지세액이 아니라 **직전 연도 법령으로 재계산한 가상 세액**을 쓰라고 명시한다. 앱이 2025년 룰셋 + 2025년 공시가격만 있으면 자체 산출된다.

재계산 시 **제외 대상** (영 §5②1호 괄호): 지방세법 제110조제3항(과표상한), 제111조제3항(탄력세율), 제112조제1항제2호(도시지역분).

반포자이는 **미발동**. 80% 세액공제 때문에 종부세가 낮아 상한에 닿지 않는다.

### 2-7. 농어촌특별세 (농특세법 §5①제8호)

```js
nongTax = finalTax * 0.20 = 1_596_540 * 0.20 = 319_308
총계    = 1_596_540 + 319_308 = 1_915_848
```

- 곱하는 대상은 **세액공제·세부담상한을 모두 반영한 최종 결정세액**이다. 산출세액이나 재산세공제 후 금액에 곱하면 안 된다
- **재산세에는 농특세가 붙지 않는다** (§5① 어느 호에도 재산세 없음)

## 3. 소방분 지역자원시설세 — 빼고 안내한다

근거: 지방세법 제146조제3항제1호·제4항 단서

| 과세표준 | 세율 | 산식 |
|---|---|---|
| 600만원 이하 | 0.04% | 과표 × 4/10,000 |
| 600만~1,300만원 | 0.05% | 2,400 + 초과분 × 5/10,000 |
| 1,300만~2,600만원 | 0.06% | 5,900 + 초과분 × 6/10,000 |
| 2,600만~3,900만원 | 0.08% | 13,700 + 초과분 × 8/10,000 |
| 3,900만~6,400만원 | 0.10% | 24,100 + 초과분 × 10/10,000 |
| 6,400만원 초과 | 0.12% | 49,100 + 초과분 × 12/10,000 |

**계산에 넣지 않는 이유**

1. 과세표준인 **건축물분 시가표준액을 프로그램이 취득할 수 없다.** 공동주택 공시가격은 토지+건물 통합가액이라 분리 불가이고, 건물분은 행안부 산정기준 고시 + 지자체장 결정이다
2. 금액이 작아(수만원대) 자산 유동화 의사결정에 영향을 주지 않는다
3. **아파트가 300% 가산 대상(제2의2호 대형 화재위험 건축물)인지 미확인이다.** 넣으면 세액이 3배로 달라질 수 있어, 틀린 숫자를 확신 있게 보여주는 최악의 결과가 된다

**권고 문구**

> 위 금액은 재산세(본세·도시지역분·지방교육세)와 종합부동산세(농어촌특별세 포함) 합계예요.
> 실제 고지서에는 소방분 지역자원시설세가 따로 붙어요(건축물 부분 기준, 보통 수만원). 이 항목은 건물 값을 따로 확인해야 계산할 수 있어 넣지 않았어요.

고지서와 대조했을 때 차이의 원인을 알 수 있어 오히려 신뢰가 올라간다.

지방교육세는 지역자원시설세에 붙지 않는다(제151조제1항 어느 호에도 없음). 서울은 표준세율 적용(서울특별시 시세 조례 제25조).

## 6. 실무 제약 — 주소만으로는 정확한 호별 조회 불가

도로명주소 문자열만으로 정확한 개별 공시가격을 고르는 구조는 현재도 불가능하다. 운영 서비스는 사용자가 동·호·전용면적까지 선택하면 PNU와 함께 2025년 서울·경기 압축 원본에서 정확히 일치하는 세대를 조회한다.

- realtyprice.kr: **동·호수 필수**(전용면적은 조회 조건이 아니라 결과 컬럼), CAPTCHA, NetFunnel 대기열, 열람 건수 제한
- 공공데이터포털 일괄 CSV: **2025.1.1 기준만 등록**, 2026년분 없음

2025년 서울·경기 공시가격은 별도 API 키나 유료 피드 없이 조회한다. 다른 기준연도, 서울·경기 밖 지역, 동·호·면적이 불완전한 입력은 자동 확정하지 않고 직접 입력 또는 새 공식 원본이 필요하다.

참고로 서울시ETAX 공식 재산세 계산기조차 입력이 공시가격 + 1세대1주택 체크박스 둘뿐이고, 세부담상한이 실제 계산에 반영되지 않는다("실제세액과 다소 차이가 있을 수 있습니다" 고지). 위택스에는 재산세 계산 기능이 아예 없다. 공식 도구도 근사치를 낸다는 사실이 오차 허용범위의 현실적 기준이다.
