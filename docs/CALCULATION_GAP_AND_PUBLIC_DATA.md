# 외부 데모 계산 괴리와 공공데이터 적용 결과

> 최신 상태(2026-08-21): 공공데이터 3종과 `/api/complexes`, 지역·단지·면적 선택 UI를 `https://aicamp-sigma.vercel.app`의 출시 경로로 관리한다.

## 결론

외부 데모의 반포자이 보유세는 종합부동산세에서 재산세 중복분 공제를 적용하지 않은 값과 세 해 모두 원 단위까지 일치했다. 외부 숫자를 그대로 복사하지 않는다.

| 연도 | 외부 데모 | 기존 우리 엔진 | 개편안 세율표까지 교정한 엔진 |
| --- | ---: | ---: | ---: |
| 2026 | 10,558,685원 | 10,116,058원 | 10,116,058원 |
| 2027 | 18,264,240원 | 14,804,784원 | 17,597,664원 |
| 2028 | 20,664,240원 | 17,204,784원 | 18,836,544원 |

위 표는 외부와 비교하기 위해 기존의 공시가격 34억 9,100만원을 그대로 넣은 결과다. 2026년 차이 442,627원은 중복분 공제 적용 후 고령·기간공제와 농어촌특별세까지 반영되며 생긴 최종 차이다. 2027·2028년에는 외부의 중복공제 누락 외에 양쪽 기존 구현 모두 세제개편안의 인상 세율표를 반영하지 않았던 문제가 겹쳐 있었다.

## 공공 원본 대조

- 출처: 국토교통부 `주택 공시가격 정보_20250626`, 공공데이터포털 데이터 3073746
- 기준일: 2025년 1월 1일
- 전체 15,580,435건의 호별 공동주택 공시가격
- 서비스 반영 범위: 2025년 서울 2,755,045세대 + 경기 4,383,843세대 = 7,138,888세대
- 정확한 조회 키: PNU + 동 + 호 + 전용면적

기존 화면의 `반포자이 120동 1002호·84.94㎡` 조합은 실제 원본과 일치하지 않았다. 해당 호는 전용 165.052㎡, 2025년 공시가격 40억 9,600만원이다. 운영 입력 화면에서는 반포자이를 포함한 모든 샘플 주소·가격 기본값을 제거했다. 검증 발췌값은 테스트와 공공데이터 응답 교차 확인에만 사용한다.

공시가격 파일에는 매매가격이 없다. 따라서 보유세에는 공공 공시가격을 사용하고, 현재 예상 매매가격은 국토교통부 아파트 매매 실거래 상세 자료에서 동일 단지·지번·전용면적의 최근 6개월 중앙값을 제안한 뒤 사용자가 확인·수정한다. 일치 거래가 없거나 API가 실패하면 직접 입력한다. 전월세는 전세와 월세를 분리해 참고 근거로만 노출하며 부분 임대수입으로 자동 대입하지 않는다. 매매 당시 취득가격은 별도 사용자 입력값이다.

이 세 공공데이터 조회와 시세 제안에는 대출액과 부모님 소득액을 사용하지 않는다. 서비스 지역도 서울·경기로 제한한다.

## 구현 원칙

1. 서울·경기 이외 PNU는 거절한다.
2. 주소검색에서 아파트로 확인되지 않은 주소는 거절한다.
3. 동·호가 맞지 않으면 같은 단지의 다른 호 가격을 쓰지 않는다.
4. 여러 주택은 재산세를 호별 계산하고, 종부세는 공시가격 합계로 계산한다.
5. 2027년 특례는 발표된 개편안의 what-if로 표시하고, 입법 확정 전에는 현재 추천 금액에 적용하지 않는다.
6. AI는 규칙 엔진이 만든 숫자만 설명하고 새 세액을 만들지 않는다.
7. 2028년 80% 공정시장가액비율은 3주택 이상 또는 조정대상지역 주택을 포함한 다주택에만 적용하고, 나머지 다주택은 70%를 유지한다.

## 현재 계산 위험

- 보유세는 여러 주택의 재산세를 각각 계산하고 공시가격 합계로 종부세를 계산합니다.
- 양도세는 주택별로 계산·합산하지만 다주택에도 12억원 초과분 비율이 적용되는 결함이 있습니다.
- `saleForYear()`에서 주택별 조정대상지역 여부가 양도세 함수로 전달되지 않습니다.

따라서 공공데이터 연결 완료와 다주택 양도세 출시 준비 완료를 같은 의미로 사용하지 않습니다.
