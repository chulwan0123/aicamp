# 외부 데모 계산 괴리와 공공데이터 적용 결과

## 결론

외부 데모의 반포자이 보유세는 종합부동산세에서 재산세 중복분 공제를 적용하지 않은 값과 세 해 모두 원 단위까지 일치했다. 외부 숫자를 그대로 복사하지 않는다.

| 연도 | 외부 데모 | 기존 우리 엔진 | 개편안 세율표까지 교정한 엔진 |
| --- | ---: | ---: | ---: |
| 2026 | 10,558,685원 | 10,116,058원 | 10,116,058원 |
| 2027 | 18,264,240원 | 14,804,784원 | 17,597,664원 |
| 2028 | 20,664,240원 | 17,204,784원 | 18,836,544원 |

위 표는 외부와 비교하기 위해 기존의 공시가격 34억 9,100만원을 그대로 넣은 결과다. 2026년 차이 442,627원은 중복분 공제 적용 후 고령·기간공제와 농어촌특별세까지 반영되며 생긴 최종 차이다. 2027·2028년에는 외부의 중복공제 누락 외에 양쪽 기존 구현 모두 세제개편안의 인상 세율표를 반영하지 않았던 문제가 겹쳐 있었다.

## 공공 원본 대조

- 출처: 국토교통부 `주택 공시가격 정보_20250626`, 공공데이터포털 데이터 3073746
- 기준일: 2025년 1월 1일
- 전체 15,580,435건의 호별 공동주택 공시가격
- 서비스 범위: 서울특별시·경기도 아파트
- 정확한 조회 키: PNU + 도로명주소 + 동 + 호 + 전용면적

기존 화면의 `반포자이 120동 1002호·84.94㎡` 조합은 실제 원본과 일치하지 않았다. 해당 호는 전용 165.052㎡, 공시가격 40억 9,600만원이다. 기본 예시는 원본에서 일치하는 `101동 101호·84.943㎡·24억 6,200만원`으로 교정했다.

공시가격 파일에는 매매가격이 없다. 따라서 보유세에는 공공 공시가격을 사용하고, 현재 예상 매매가격과 매매 당시 취득가격은 별도 값으로 유지한다. 현재 예상 매매가격·취득연도·매매 당시 가격은 사용자가 수정할 수 있다. 현재 예상 매매가격은 매도·주택연금·현금흐름 시나리오에 사용한다.

## 구현 원칙

1. 서울·경기 이외 PNU는 거절한다.
2. 주소검색에서 아파트로 확인되지 않은 주소는 거절한다.
3. 동·호가 맞지 않으면 같은 단지의 다른 호 가격을 쓰지 않는다.
4. 여러 주택은 재산세를 호별 계산하고, 종부세는 공시가격 합계로 계산한다.
5. 2027년 이후 값은 2026년 세제개편안의 입법 확정을 가정한 예상치로 표시한다.
6. AI는 규칙 엔진이 만든 숫자만 설명하고 새 세액을 만들지 않는다.
7. 2028년 80% 공정시장가액비율은 3주택 이상 또는 조정대상지역 주택을 포함한 다주택에만 적용하고, 나머지 다주택은 70%를 유지한다.
