# SILVER 현행 디자인 시스템 명세

문서 버전: 1.1  
기준일: 2026-08-20

## 적용 원칙

이 명세는 새로운 스타일을 만드는 기준이 아니라 현재 구현을 유지하고 확장하기 위한 기록이다. 실제 화면과 이 문서가 다르면 작업 시작 시점의 실제 화면을 우선하고, 차이를 문서에 반영한다.

## 기반 파일

- 진입점: `assets/design-system/styles.css`
- 색상: `assets/design-system/tokens/colors.css`
- 타이포그래피: `assets/design-system/tokens/typography.css`
- 간격·라운드·모션: `assets/design-system/tokens/spacing.css`
- 화면별 현행 스타일: `index.html`의 `<style>`

토큰 파일을 복제하거나 화면별로 다른 값을 새로 만들지 않는다.

## 레이아웃

### 서비스 영역

- `.app` 최대 너비: `500px`
- 모바일: 화면 너비 전체를 사용하고 배경은 흰색
- 데스크톱: 전체 배경은 회색, 중앙 서비스 영역만 최대 500px 흰색
- 기본 화면 좌우 여백: `20px`
- 섹션 간 기본 리듬 토큰: `52px`
- 가로 넘침: 발생하지 않아야 함

### 고정 영역

- 토큰 기준 상단 내비게이션: `48px`, 현행 최종 오버라이드 높이: `52px`
- 입력 1~8단계 상단 바: 현행 52px와 하단 `3px` 진행 막대
- 주요 CTA: 화면 하단 고정, 최대 너비 500px, 안전 영역 포함
- 홈·마이 하단 탭: 데스크톱 최대 500px, 모바일 전체 너비
- 하단 탭 기본 높이: 72px, 모바일에서는 안전 영역을 포함한 64px 기반
- 결과 요약 상단 바: `64px / 1fr / 64px` 그리드, 오른쪽 `홈으로` 링크

### 시작 스플래시

- 서비스 최초 진입 화면은 `#start`다. 홈은 기본 화면으로 사용하지 않는다.
- 스플래시는 전체 화면 높이를 사용하고 하단에 시작 버튼을 배치한다.
- 배경: `#0987D5`와 하단 그라데이션
- 중앙 브랜드 로고 너비: 180px
- 태그라인: 흰색 Lifeplus 17px / 24px / 500
- 배경 영상: `silver-intro.mp4`, 화면 하단 정렬
- 시작 버튼: `부모님의 노후 준비를 시작해요`
- 시작 버튼을 누른 뒤에만 `#home`으로 이동한다.
- 빈 해시와 알 수 없는 해시는 스플래시로 처리한다.

### 반응형 분기

- `max-width: 500px`: 모바일 전체 너비와 안전 영역 적용
- `max-width: 380px`: 좁은 화면용 그리드와 글자 크기 보정

새 breakpoint를 추가하지 않는다. 정말 필요한 경우 기존 500px 또는 380px 분기 안에서 해결한다.

## 색상

### 브랜드

| 용도 | 토큰 | 값 |
|---|---|---|
| 브랜드 주색 | `--color-orange-600` | `#F37521` |
| 브랜드 밝은색 | `--color-orange-100` | `#FFF2E5` |
| 브랜드 진한색 | `--color-orange-700` | `#E5640E` |

현재 `index.html`의 `--blue`는 과거 선택자 호환을 위해 유지되는 변수명이며 실제 값은 브랜드 오렌지다.

```css
:root {
  --blue: var(--color-orange-600, #f37521);
  --color-blue-100: var(--color-orange-100, #fff2e5);
  --color-blue-200: var(--color-orange-200, #ffe4cc);
  --color-blue-300: var(--color-orange-300, #ffcea6);
}
```

이 별칭을 파란색 의미로 해석하거나 이름을 변경하지 않는다. 기존 선택자 호환을 위해 그대로 둔다.

## 간격과 형태

### 기본 단위

- 기본 간격 단위: `4px`
- 화면 좌우 여백: `20px`
- 최소 탭 영역: `44px`

### 라운드

| 토큰 | 값 | 주 사용처 |
|---|---:|---|
| `--radius-lg` | 8px | 썸네일, 목록 미디어 |
| `--radius-xl` | 12px | 카드, 큰 버튼 |
| `--radius-2xl` | 16px | 팝업 |
| `--radius-3xl` | 24px | 바텀시트 |
| `--radius-pill` | 300px | 태그, 배지 |

홈 결과 요약 카드 `.start-preview-card`는 현행 예외로 `20px` 라운드를 사용한다.

### 그림자

- 기본 디자인 시스템은 거의 평면이며 테두리와 배경으로 계층을 만든다.
- 기본 카드 토큰: `0 1px 2px rgba(20, 20, 21, 0.04)`
- 홈 결과 요약 카드 현행 예외: `0 10px 26px rgba(24, 28, 34, 0.07)`
- 바텀시트는 그림자가 아니라 검정 45% 오버레이를 사용한다.

다른 그림자를 새로 추가하지 않는다.

## 핵심 컴포넌트

### 주요 버튼

- 높이: `56px`
- 좌우 패딩: `20px`
- 라운드: `12px`
- 배경: 브랜드 주색
- 텍스트: 흰색, 17px, 700
- 포커스: 기존 3px 포커스 링 유지

홈 액션 버튼은 최소 높이 54px이며, 결과 카드 안에서 두 버튼이 상하 한 열로 배치된다.

### 카드

- 기본: 흰색 배경, 옅은 테두리, 12px 라운드
- 홈 결과 요약: 20px 라운드, 20px 16px 패딩, 지정 그림자
- 카드 안 콘텐츠 순서와 버튼 위치를 바꾸지 않는다.

### 입력과 선택

- 선택 버튼 최소 높이: 52px
- 입력 높이: 52px, 라운드: 12px
- 선택 트리거: 최소 56px, 라운드: 12px
- 입력 페이지 `.stack`: 기본 간격 42px, 상단 여백 40px
- 주택 반복 영역: 내부 간격 20px, 연속 필드 보정 10px
- 주택 수·공동명의 반복 묶음: 38px 간격
- 선택 상태: 브랜드 테두리와 밝은 브랜드 배경
- 필드 선택은 기존 바텀시트 패턴을 사용
- 브라우저 기본 `<select>` 모양을 노출하지 않는다.
- 원본 `.choices`와 `select.select`는 스크립트가 숨기고 `.select-trigger`로 대체한다.
- 트리거 오른쪽의 24px 아래 방향 아이콘을 유지한다.

### 바텀시트

- 최대 너비: 500px
- 상단 라운드: 24px
- 오버레이: 검정 45%
- 옵션 최소 높이: 58px
- 선택 표시: 현행 체크 모양과 브랜드 색 유지

### 콘텐츠 목록

- 행: 이미지, 타이틀, 설명 한 줄
- 썸네일 외곽: `80px × 60px`
- 썸네일 배경: `#155BB0`
- 내부 이미지: `64px × 64px`, `object-fit: contain`
- 타이틀: 18px / 26px
- 설명: 15px / 23px, 한 줄 초과 시 말줄임

### 홈 뉴스 배너

- 가로 스크롤 레일
- 카드 너비 286px, 높이 154px
- 간격 12px
- `scroll-snap` 유지
- 각 카드의 배경, 이미지, 문구 위치를 변경하지 않는다.

### 상단 진행 막대

- 입력 단계 1~8에만 노출
- 높이 3px
- 단계별 폭: 1/8에서 8/8까지 12.5% 단위의 기존 비율 유지
- 상단 바와 함께 고정된 시각 구조를 유지
- 단계 숫자는 헤더 아래 오른쪽 20px 위치에 표시한다.

### 분석 중 화면

- 컨테이너: 전체 화면 높이, 오버플로 숨김
- 영상: 화면 전체 절대 배치, `object-fit: cover`
- 오버레이: 위쪽 청색 반투명에서 아래쪽 투명·어두운 색으로 이어지는 그라데이션
- 메시지: 상단 약 200px에서 중앙 정렬, 흰색 텍스트와 약한 그림자
- 영상: `autoplay muted loop playsinline preload="auto"`
- 결과 전환: 5초

### 결과 요약 화면

- 기본 배경은 흰색이며 첫 결과 상태를 어두운 히어로 카드로 만들지 않는다.
- 결과 상태 타이틀은 28px / 38px, 설명은 18px / 28px이다.
- 현금흐름은 카드 3열이 아니라 1열의 좌우 정렬 금액 행 3개다.
- 주요 섹션 사이에는 높이 10px의 회색 구분 영역을 사용하고 상하 50px 여백을 둔다.
- 전체 결과 항목 간 간격은 80px이며 중간에 1px 구분선을 둔다.
- 전체 결과의 기존 카드 외곽선과 그림자는 제거된 평면 섹션 형태를 유지한다.
- 전체 결과 제목은 24px / 34px, 분류 라벨은 16px / 24px이다.
- 핵심 수치 행은 17px / 25px 좌우 정렬이다.
- 세금은 3열 카드가 아니라 1열 금액 행 3개다.
- 상세 버튼은 최소 높이 46px, 좌우 20px, 8px 라운드, 외곽선형이며 화살표가 없다.
- FAQ는 외곽 카드가 없는 `<details>` 목록이며 항목 사이 1px 구분선을 유지한다.
- 결과 하단 CTA는 카카오 노랑 공유 버튼과 흰색 외곽선 상담 버튼을 상하로 고정한다.

### 결과 상세 화면

- `#tax`, `#cashflow`, `#downsizing`, `#recommendation`은 `결과 n/4` 단계 표기를 유지한다.
- `#home-pension`, `#inheritance`는 `상세` 표기를 유지한다.
- 모든 상세 화면 하단에 `결과 요약으로 돌아가기` 고정 버튼을 유지한다.
- 요약 화면의 각 `data-go` 연결을 다른 상세 화면으로 바꾸지 않는다.

## 에셋과 모션

### 영상

- 인트로, 시작 카드, 분석 배경 영상의 파일 경로와 비율을 유지한다.
- 재생 속성, poster, object-fit, 크롭, 위치를 임의 변경하지 않는다.
- 화면이 숨겨질 때 일시정지하고 다시 노출될 때 재생하는 `syncAutoplayVideos()` 동작을 유지한다.
- 영상 로드 실패를 숨기기 위해 다른 에셋으로 자동 대체하지 않는다. 오류를 보고한다.

### 홈 인사 애니메이션

- 세 프레임이 총 7.5초 주기로 순환한다.
- 각 프레임의 지연과 이동·회전 동작을 유지한다.
- `prefers-reduced-motion`에서는 첫 프레임만 정적으로 보이는 현행 처리를 유지한다.

### 콘텐츠 이미지

- `calculator.png`, `house.png`, `moving-box.png`, `teacup.png`를 각각 현재 항목에 그대로 사용한다.
- 아이콘으로 다시 교체하지 않는다.
- 네 썸네일의 외곽 배경은 모두 `#155BB0`이다.

## 신규 기능 확장 규칙

### 기존 화면 안에 기능 추가

1. 시각 요소 추가 없이 기존 버튼과 필드에 연결한다.
2. 값이 필요한 곳에만 `data-*` 훅을 추가한다.
3. 기존 컴포넌트의 상태와 문구를 재사용한다.
4. API 지연이나 오류가 레이아웃을 밀지 않도록 현재 영역 안에서 처리한다.
5. 입력값은 숨겨진 원본 필드에 먼저 반영하고 기존 트리거·요약 동기화 함수를 호출한다.
6. 결과값은 현재 결과 노드에 직접 주입하고 섹션을 재렌더링하지 않는다.

### 신규 페이지 추가

1. 같은 목적의 기존 페이지를 템플릿으로 고른다.
2. 기존 토큰과 컴포넌트만 조합한다.
3. 페이지 전용 CSS로 범위를 제한한다.
4. 전역 토큰과 공용 클래스는 수정하지 않는다.
5. 모바일 320px부터 데스크톱까지 검증한다.
